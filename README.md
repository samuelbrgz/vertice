# Vértice

**Sistema de Gerenciamento de Torneios**

O Vértice é uma aplicação desktop desenvolvida em Java para organizar e gerenciar torneios, desde a inscrição das equipes até a definição do campeão.

O projeto está sendo desenvolvido como trabalho acadêmico da disciplina de Programação Orientada a Objetos (POO).

## Funcionalidades planejadas

- Cadastro e gerenciamento de equipes.
- Criação e gerenciamento de torneios.
- Inscrição de equipes em diferentes torneios.
- Sorteio automático dos confrontos.
- Geração de chaves de eliminação simples.
- Passagem automática de rodada (*bye*) quando necessário.
- Registro dos resultados das partidas.
- Avanço automático dos vencedores até a definição do campeão.

## Tecnologias

- Java
- Java Swing (JFrame e JPanel)
- Apache Maven
- Banco de dados a definir

## Estado do projeto

Em desenvolvimento. Atualmente na fase de planejamento e configuração do ambiente.

## Objetivo acadêmico

Aplicar conceitos de Programação Orientada a Objetos, modelagem de sistemas, interfaces gráficas e persistência de dados.
